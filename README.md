## ۱. این سیستم چیست؟

**BaskolPanel** یک پنل وب برای شرکت‌های حمل‌ونقل، گدام‌داری و بارچلانی است. با این سیستم می‌توانید:

- مشتریان و اجناس (بار) را ثبت کنید
- کانتینرها را مدیریت و بارگیری کنید
- موترها و سفرهای زمینی را پیگیری کنید
- موقعیت و مسیر بار را ثبت کنید و **هزینه مسیر** را در همان بخش وارد کنید
- هزینه‌ها و دریافت‌های مشتری را ثبت کنید
- صندوق (نقدی) را مدیریت کنید
- باسکول (وزن‌کشی) را ثبت کنید
- تحویل بار به مشتری را مستند کنید
- گزارش مفاد/ضرر، طالبات، صندوق و حساب هر مشتری را ببینید

سیستم از **سه زبان** پشتیبانی می‌کند: **فارسی**، **پشتو** و **انگلیسی**. زبان از منوی بالای صفحه قابل تغییر است.

## ۳. نصب و راه‌اندازی اولیه

### گام ۱ — دریافت پروژه و نصب وابستگی‌ها

```bash
cd BaskolPanel-NodeJS
npm install
```

### گام ۲ — ساخت پایگاه داده

در MySQL یک دیتابیس بسازید، مثلاً:

```sql
CREATE DATABASE Baskol_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### گام ۳ — تنظیم فایل محیط (`.env`)

فایل `.env.example` را کپی کنید:

```bash
copy .env.example .env
```

(در لینوکس/مک: `cp .env.example .env`)

مقادیر مهم را پر کنید:

```env
APP_URL=http://localhost:8000
PORT=8000

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=Baskol_db
DB_USERNAME=root
DB_PASSWORD=رمز_شما

SESSION_SECRET=یک_رشته_تصادفی_طولانی

# اختیاری — برای کاربر مدیر اولیه
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=password123
ADMIN_NAME=مدیر سیستم
```

### گام ۴ — ساخت جداول پایگاه داده

```bash
npm run migrate
```

این دستور جداول را از `database/schema.sql` می‌سازد و به‌روزرسانی‌های لازم را اعمال می‌کند.

### گام ۵ — ساخت کاربر مدیر

```bash
npm run seed
```

کاربر مدیر با ایمیل و رمز تعریف‌شده در `.env` (یا مقادیر پیش‌فرض) ساخته می‌شود.

### گام ۶ — ساخت فایل‌های ظاهری (CSS/JS)

```bash
npm run build
```

### گام ۷ — اجرای سرور

**حالت توسعه** (با ری‌استارت خودکار):

```bash
npm run dev
```

**حالت تولید**:

```bash
npm start
```

مرورگر را باز کنید: **http://localhost:8000**

## ۴. ورود به سیستم

1. به آدرس برنامه بروید (مثلاً `http://localhost:8000`)
2. ایمیل و رمز مدیر را وارد کنید
3. پس از ورود، به **داشبورد** هدایت می‌شوید

> اولین بار حتماً رمز پیش‌فرض را در **تنظیمات → پروفایل** یا از طریق مدیر، برای کاربر admin تغییر دهید.

## ۵. آشنایی با رابط کاربری

### منوی کناری (سمت راست)

| منو | کاربرد |
|-----|--------|
| **داشبورد** | خلاصه وضعیت مالی و عملیاتی — با کلیک روی هر کارت جزئیات |
| **باسکول** | ثبت رسید وزن‌کشی |
| **معرفی‌ها** | میانبر به تمام بخش‌های ثبت اطلاعات پایه |
| **گزارشات** | مرکز گزارش‌های مالی، بار، موتر و ... |
| **تنظیمات** | نام سیستم، شرکت، ارز، پشتیبان‌گیری |

### بخش معرفی‌ها

صفحه **معرفی‌ها** (`/introductions`) دروازه ورود به ماژول‌های اصلی است:

- کارمندان / کاربران
- مشتریان
- موترها و سفر موتر
- کانتینرها، اجناس، بارگیری
- موقعیت بار، هزینه‌ها، دریافت‌ها
- صندوق، شرکا، معاش
- سود/زیان موتر

### دکمه‌های رایج

- **ثبت / افزودن** — باز کردن فرم جدید
- **ویرایش** — تغییر رکورد موجود
- **حذف** — حذف نرم (با تأیید)
- **جستجو** — فیلتر در جدول‌ها
- **چاپ** — در برخی گزارش‌ها

## ۶. ترتیب پیشنهادی کار (گردش کامل)

برای یک بار از **مبدأ تا تحویل مشتری**، این ترتیب پیشنهاد می‌شود:

```
۱. تنظیمات اولیه (صندوق، نام شرکت، ارز)
        ↓
۲. ثبت مشتری
        ↓
۳. ثبت جنس (بار) برای آن مشتری
        ↓
۴. ثبت کانتینر (مسیر دریایی/زمینی)
        ↓
۵. بارگیری — وصل کردن جنس به کانتینر + سهم کرایه
        ↓
۶. ثبت موقعیت بار + هزینه مسیر (حساب مشتری)
        ↓
۷. ثبت هزینه‌های دیگر (شرکت / کانتینر) در بخش هزینه‌ها
        ↓
۸. (اختیاری) ثبت موتر → سفر موتر → بار و کرایه سفر → مصارف سفر
        ↓
۹. ثبت دریافت پول از مشتری
        ↓
۱۰. تحویل بار به مشتری
        ↓
۱۱. بررسی حساب مشتری، داشبورد و گزارشات
```

### مسیر جایگزین — حمل با موتر (بدون کانتینر)

```
مشتری → جنس → موتر → سفر موتر → بار روی سفر + کرایه → مصارف سفر → دریافت → تحویل
```

## ۷. راهنمای بخش‌ها

### ۷.۱ تنظیمات و صندوق (اول کار)

**مسیر:** تنظیمات → `/settings`

- نام سیستم و شرکت را برای فاکتور و چاپ تنظیم کنید
- **ارز پیش‌فرض** و ارزهای فعال (USD، AFN، CNY و ...) را مشخص کنید
- تعداد ردیف در هر صفحه جدول را تنظیم کنید

**صندوق:** `/cashbox`

- یک **صندوق اصلی** با موجودی افتتاحیه بسازید
- هر **هزینه** ثبت‌شده (در بخش هزینه‌ها، موقعیت بار، یا سفر موتر) به‌صورت خودکار از صندوق کم می‌شود
- هر **دریافت مشتری** به صندوق اضافه می‌شود
- حرکت‌های دستی (دریافت، مصرف، برداشت، اصلاحیه) هم قابل ثبت است

---

### ۷.۲ کارمندان / کاربران

**مسیر:** `/users` (فقط مدیر سیستم)

- کاربر جدید با **نقش** (مدیر، حسابدار، انباردار، ...) بسازید
- برای نقش «کاربر سفارشی» دسترسی هر صفحه را تیک بزنید
- هر کاربر فقط صفحاتی را می‌بیند که مجاز است

---

### ۷.۳ مشتریان

**مسیر:** `/customers`

1. **ثبت مشتری جدید**
2. نام، کد، تماس، شرکت و آدرس را وارد کنید
3. ذخیره

مشتری پایه تمام اجناس، دریافت‌ها و گزارش حساب است.

---

### ۷.۴ اجناس (ثبت بار)

**مسیر:** `/cargo-items`

1. **ثبت جنس جدید**
2. مشتری را انتخاب کنید
3. نام جنس، تعداد کارتن، ابعاد (طول × عرض × ارتفاع) و وزن را وارد کنید
4. **حجم (CBM)** به‌صورت خودکار محاسبه می‌شود
5. وضعیت جنس را انتخاب کنید (ثبت‌شده، در مسیر، رسیده، ...)

> **تنظیمات حساب مشتری** (نوع صورت‌حساب، کمیشن، قرارداد) در همین فرم ثبت جنس نیست — از دکمه **«حساب مشتری»** در لیست اجناس یا صفحه `/cargo-items/:id/billing` انجام می‌شود.

---

### ۷.۵ کانتینرها

**مسیر:** `/containers`

1. شماره کانتینر، کشتی، مبدأ، مقصد و کرایه کل را ثبت کنید
2. وضعیت را به‌روز نگه دارید (بارگیری، در مسیر، روی کشتی، رسیده، ...)

---

### ۷.۶ بارگیری کانتینر

**مسیر:** `/container-loading`

1. کانتینر مورد نظر را انتخاب کنید
2. جنس مشتری را به کانتینر **اضافه** کنید
3. تعداد کارتن، حجم و وزن بارگیاری‌شده را وارد کنید
4. **سهم کرایه** هر جنس از کرایه کل کانتینر محاسبه می‌شود

این سهم در گزارش طالبات و حساب مشتری استفاده می‌شود.

---

### ۷.۷ موقعیت بار و هزینه مسیر

**مسیر:** `/cargo-locations`

اینجا **هم موقعیت** و **هم هزینه مسیر** ثبت می‌شود:

1. **ثبت موقعیت جدید**
2. کانتینر و **جنس** را انتخاب کنید
3. مرحله (گدام، گمرک، ...)، نام موقعیت و وضعیت را وارد کنید
4. در بخش **«هزینه مسیر (حساب مشتری)»**:
   - مبدأ و مقصد (مثلاً چین → مرز)
   - مبلغ هزینه
   - تیک «قابل دریافت از مشتری» (پیش‌فرض فعال)

**نکته:** اگر مبلغ هزینه وارد کنید، **انتخاب جنس الزامی** است. هزینه:
- در **حساب مشتری** (حالت تفکیکی) نمایش داده می‌شود
- از **صندوق** کم می‌شود
- در **گزارش هزینه‌ها** و **داشبورد** (سربار) دیده می‌شود

از صفحه حساب مشتری می‌توانید با لینک مستقیم به همین فرم بیایید (`?form=create&cargo=شناسه_جنس`).

---

### ۷.۸ هزینه‌ها

**مسیر:** `/expenses`

هزینه‌ها بر اساس **نوع (scope)** دسته‌بندی می‌شوند:

| نوع | کاربرد |
|-----|--------|
| **شرکت** | هزینه عمومی دفتر |
| **جنس** | هزینه مرتبط با یک جنس خاص |
| **کانتینر** | هزینه کل کانتینر (بین اجناس داخل آن تقسیم می‌شود) |
| **سفر موتر** | از بخش سفر موتر هم sync می‌شود |

فیلدهای **مبدأ/مقصد مسیر** و **قابل دریافت از مشتری** برای هزینه‌های مرتبط با بار مفید است.

---

### ۷.۹ دریافت‌ها (پرداخت مشتری)

**مسیر:** `/payments`

1. مشتری، مبلغ، ارز، تاریخ و روش پرداخت را ثبت کنید
2. می‌توانید دریافت را به یک **جنس** خاص وصل کنید
3. مبلغ در **صندوق** ثبت و در **حساب مشتری** از باقی‌مانده کم می‌شود

---

### ۷.۱۰ موترها

**مسیر:** `/vehicles`

- پلاک، نوع، ظرفیت، راننده پیش‌فرض و مالک را ثبت کنید

---

### ۷.۱۱ سفر موتر

**مسیر:** `/vehicle-trips`

**مرحله ۱ — ثبت سفر:**
- موتر، مبدأ، مقصد، راننده

**مرحله ۲ — جزئیات سفر** (بعد از ذخیره، روی سفر کلیک کنید):
- **بار و کرایه:** هر جنس با وزن و کرایه
- **مصارف سفر:** سوخت، گمرک، ... (خودکار از صندوق کم می‌شود)

**مرحله ۳ — تحویل:**
- از همان صفحه می‌توانید به **ثبت تحویل** بروید

### ۷.۱۲ تحویل‌دهی

**مسیر:** `/deliveries`

## ۸. حساب مشتری و صورت‌حساب

**مسیر:** از لیست اجناس → دکمه **«حساب مشتری»** یا `/cargo-items/:id/billing`

### دو نوع حساب

#### ۱. تفکیکی (itemized) — پیش‌فرض

- هر **هزینه مسیر** (ثبت‌شده در **موقعیت بار**) جداگانه جمع می‌شود
- **کمیشن** (درصد) روی جمع هزینه‌ها محاسبه می‌شود
- **مبلغ قابل دریافت** = هزینه‌ها + کمیشن − پرداخت‌های مشتری

#### ۲. قراردادی (fixed contract)

- یک **مبلغ ثابت** توافق‌شده (مثلاً از ایران تا افغانستان)
- مسیر قرارداد را یادداشت کنید
- باقی‌مانده = مبلغ قرارداد − پرداخت‌ها

### در همین صفحه

- تنظیم نوع حساب و کمیشن/قرارداد
- لیست هزینه‌های مسیر (فقط نمایش — ثبت جدید از **موقعیت بار**)
- ثبت دریافت (لینک به دریافت‌ها)
- تاریخچه پرداخت‌ها

### گزارش کامل مشتری

**مسیر:** گزارشات → **حساب مشتریان** (`/reports?type=customer-accounts`)

- انتخاب مشتری
- نمایش همه اجناس، مسیرها، هزینه‌ها، دریافت‌ها، بارگیری و ...

## ۹. داشبورد

**مسیر:** `/dashboard`

کارت‌های خلاصه (با کلیک → جزئیات):

| کارت | معنی |
|------|------|
| کانتینرها در مسیر | تعداد کانتینرهای فعال |
| مصارف شرکت | هزینه‌های نوع «شرکت» |
| مصارف سربار | هزینه جنس + کانتینر + مسیر |
| مفاد / ضرر شرکت | کرایه کانتینر − مصارف |
| موجودی صندوق | محاسبه از افتتاحیه + حرکت‌ها |
| رسیده و تحویل‌نشده | اجناس در گدام/مقصد |
| طالبات | مبلغ قابل دریافت از مشتریان |
| بدهی‌ها | هزینه‌های پرداخت‌نشده |
| منبع مفاد | کل کرایه کانتینرها |
| **موترهای فعال** | تعداد موترهای ثبت‌شده |
| **سفرهای در مسیر** | سفرهای تحویل‌نشده |
| **کرایه موترها** | مجموع کرایه سفرها |
| **مصارف سفر موتر** | هزینه‌های سفر |
| **سود/زیان موترها** | کرایه − مصارف سفر |

## ۱۰. گزارشات

**مسیر:** `/reports-hub`

| گزارش | محتوا |
|--------|--------|
| گزارش عمومی | خلاصه کلی سیستم |
| موقعیت بار | وضعیت اجناس و مسیر |
| هزینه‌ها | تفکیک شرکت / جنس / کانتینر / موتر |
| دریافت‌ها | پرداخت مشتریان |
| صندوق | حرکت‌ها و موجودی |
| کانتینرها | لیست و کرایه |
| بارگیری | اجناس داخل هر کانتینر |
| باسکول | رسیدهای وزن |
| اجناس | لیست بارها |
| مفاد و ضرر | تحلیل درآمد و هزینه |
| فاکتور مشتری | صدور فاکتور |
| **حساب مشتریان** | گزارش جامع هر مشتری |
| سفر موتر | بار و کرایه سفرها |
| تحویل | رسیدهای تحویل |
| شرکا / معاش | گزارش‌های مالی پرسنلی |
| سود/زیان موتر | به تفکیک پلاک |

در اکثر گزارش‌ها **فیلتر تاریخ** و **خروجی CSV** وجود دارد.

## ۱۱. کاربران و سطح دسترسی

### نقش‌های پیش‌فرض

| نقش | دسترسی معمول |

## ۱۳. نکات مهم

1. **ترتیب ثبت:** اول مشتری و جنس، بعد کانتینر/موتر، بعد هزینه و دریافت
2. **هزینه مسیر** را در **موقعیت بار** ثبت کنید، نه در فرم ثبت جنس
3. **حساب مشتری** را از دکمه «حساب مشتری» روی هر جنس تنظیم کنید
4. هر هزینه ثبت‌شده **از صندوق کم** می‌شود — موجودی صندوق را اول تنظیم کنید
5. **بارگیری کانتینر** برای تقسیم کرایه بین مشتریان ضروری است
6. برای موتر: اول سفر، بعد بار و کرایه، بعد مصارف
7. قبل از به‌روزرسانی برنامه: **`npm run migrate`** و **`npm run build`**
8. زبان رابط از منوی بالا — fa / ps / en

## ۱۴. عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| صفحه سفید / بدون استایل | `npm run build` را اجرا کنید |
| خطای اتصال دیتابیس | `.env` و سرویس MySQL را بررسی کنید |
| جدول وجود ندارد | `npm run migrate` |
| نمی‌توانم وارد شوم | `npm run seed` — ایمیل/رمز `.env` |
| هزینه در حساب مشتری نیست | جنس انتخاب شده؟ «قابل دریافت از مشتری» فعال؟ نوع حساب «تفکیکی»؟ |
| صندوق منفی | موجودی افتتاحیه یا دریافت‌های ثبت‌نشده |
| دسترسی به صفحه ندارم | مدیر نقش/دسترسی کاربر را بررسی کند |

### دستورات مفید

```bash
npm run dev       # اجرای توسعه
npm start         # اجرای تولید
npm run migrate   # به‌روزرسانی دیتابیس
npm run seed      # ساخت/به‌روزرسانی مدیر
npm run build     # ساخت CSS/JS
npm run check     # بررسی syntax کد
```
